    Hardware Architecture & Pipelining

    1. RDOQ 算法微观原理与 C-Model RD-Cost 计算机制

    在深入硬件优化前，必须厘清 RDOQ 的算法本质，并将其与宏观的 RDO 严格区分。在 C-Model 的 simpleRdoQuant() 函数中，RDOQ 执行的是最底层的“系数级贪婪寻优”。

    核心概念厘清：RDO vs RDOQ
    RDO (Mode Decision): 宏观层面的模式决策。评估整个块最终重建像素的 SAD/SSE 畸变与总体比特消耗。
    RDOQ (Quantization): 微观层面的量化优化。在选定 Mode 之后，针对每一个 DCT 频率系数，评估“量化为哪个具体整数（包括 0）”能获得最优的局部 Cost 表现。

    C-Model 的微观 PK 机制

    1. RDOQ 核心 Cost 公式:
      在 C-Model 中，RDOQCOST_S 宏被展开为严格的整数定点数学形式：
      $$Cost = \underbrace{\left( d^2 \cdot 2^{scaleBits} \right)}_{\text{RDOQDIST\_S}(d)} + \underbrace{\left\lfloor \frac{\lambda \cdot bits}{2^{shift}} \right\rfloor}_{\text{RDOQBINCOST\_S}(bits)}$$
      • $d = |C_{trans} - C_{inv\_quant}|$：原始变换系数与反量化重建系数的绝对差值。
      • $scaleBits$：用于将平方误差 (SSE) 定点放大的位移常量。
      • $bits$：由 rdoq_coeff_est() 模拟 CABAC 状态机得到的熵编码比特数估计。
      • $\lambda$ 与 $shift$：拉格朗日乘子及其对应的定点化右移常量。
    2. 单系数层面的“贪婪 PK”:
      对于任何一个非零系数，C-Model 会生成候选数组：absLevels[3] = {maxQuantLevel, maxQuantLevel - 1, 0}。它遍历这些候选值，计算 RDOQCOST_S，并贪婪地选取使得 Cost 绝对最小的 Level。
    3. 系数组 (CG) 的“一刀切 PK”:
      完成 4x4 系数级的独立寻优后，它会将整个 4x4 系数组 (Sub-Block) 暴切为 0 的代价 costZeroCG = blockZeroCosts[iSubBlk] + sbfCost[0] 与保留精英系数的总体代价进行比较。若全切为 0 更划算，则强制关闭 Sub-Block Flag (SBF)，实现一刀切剪枝。

    2. 收益分布与取舍策略 (RDOQ Pruning Strategy)

    RDOQ 作为压缩率“微雕”工具，收益高度集中于边缘高频系数。工业界在架构层面必须做出极端的收益/吞吐权衡。

    核心架构抉择：弃大保小
    强制关闭大块（CU16/CU32/CU8）的 RDOQ 以满足时序吞吐限制，死保 CU4/TU4 的 RDOQ (wf4)。仅牺牲约 0.5% 的 BD-Rate，换取流水线不会因为长周期状态机陷入瘫痪。

    自然语言算法步骤 (Algorithm Steps)

    1. 尺寸侦测: 控制逻辑从上游截获当前流入 TU/CU 的像素尺寸元数据。
    2. 大块旁路剔除: 若检测到 Size > 4x4 (如 8x8、16x16)，直接封锁 RDOQ 硬件入口，迫使数据流入极简的普通标量量化 (SQ) 模块，迅速输出残差。
    3. 精英放行: 若检测到 Size == 4x4，则判定为高频收益敏感区，立刻拉高使能信号，将数据与 Context 喂入全量 RDOQ 引擎。
    4. 高频提纯: 引擎针对这些 4x4 精英块进行深度 Cost 寻优，最终压榨出极限的 Bincost 并输出纯净的高频残差。

    3. 帧内环路死锁破解 (Intra Feedback Loop Bypass)

    在 wf4 模块中，吞吐目标为 1 pix/clk（即每 16 拍处理一个 4x4 块）。但 RDOQ 会引入至少 8 拍延迟，使得总体重构反馈链路长达 24 拍，远超 16 拍预算。

    破局点：前馈重建旁路 (Fast Recon Bypass)
    为打破帧内相邻块的空间依赖链，强制预测重建像素跳过 RDOQ，走 Fast Loop 快速闭环。而 RDOQ 则在独立的 Slow Loop 中计算真实码流。

    自然语言算法步骤 (Algorithm Steps)

    1. 源头分流: 像素在完成 DCT 与简单量化 (SQ) 之后，信号兵分两路，分别进入互不干涉的独立赛道。
    2. 快环抢跑 (Fast Loop): 第一路数据完全无视后续的 RDOQ，直接冲进反量化与 IDCT。仅仅 12 拍后即刻生成“快速预测重建像素”，并在第 13 拍立刻送给隔壁紧邻的块作为 Intra 空间预测源。死锁瞬间破解。
    3. 慢环细雕 (Slow Loop): 第二路数据则带着 SQ 的结果，不慌不忙地进入 RDOQ 核心计算池，耗时 20 拍以上计算出真实的最佳 Level 和 CABAC 码流估算。
    4. 合流决断: 最终写入比特流的数据完全采纳 Slow Loop 的高精结果；Fast Loop 的粗糙数据在发挥完“打破流水线气泡”的垫脚石作用后即被丢弃。

    4. 静态上下文预生成 (Static Context Generation)

    传统的 Trellis 网格寻优存在深度的系数间因果依赖。在硬件设计中，必须采用“局部独立近似”来替换“全局网格搜索”，为彻底打平流水线铺平道路。

    自然语言算法步骤 (Algorithm Steps)

    1. 静态快照剥离: 抛弃原本动态更新上下文的做法，改为在第 1 拍利用初步 SQ 的结果，一次性暴力预生成 16 个系数的 CABAC Context 静态快照。这彻底切除了系数计算之间的时序依赖链。
    2. 搜索空间极简压缩: 舍弃了从 0 一直搜索到最优 Level 的传统庞大循环，硬件判定器强行锁定只有原始 Q 和减弱一档的 Q-1 两个候选目标参与角逐。
    3. 并行兵团展开: 点亮 16 个完全独立的物理计算单元 (Compute Unit)。这 16 个单元在同一时钟周期内，各自抱着自己的 Context 快照，疯狂且独立地计算自己所属系数的 Q Cost 和 Q-1 Cost。
    4. 决出局部霸主: 16 个单元内部的比较器瞬间各自决出 Cost 最小的优胜 Level。最终通过总线拼合，形成当前 4x4 块的伪全局最优解。

    5. 终极吞吐利器：Two-Stage Fast RDOQ Pruning

    为了满足严苛的 4K/8K 帧率，单纯在底层进行流水线化仍显不足，必须从宏观算法上源头把控，控制 RDOQ 模块的绝对启动频次。

    两级 Candidate 剪枝过滤：
    前级采用标量量化 (SQ) 与 CABAC 初估，选出 Top-2 Best Candidates。仅将这 2 个 Candidate 扔入深度 RDOQ 流水线。牺牲极小 BD-Rate，削减 70% 的面积与时间开销，完美闭环 16 clk 预算！

    自然语言算法步骤 (Algorithm Steps)

    1. 海选起跑线: 帧内预测模块筛选出的 16 个潜在最优模式 (Candidates) 汹涌涌入流水线。
    2. 廉价粗筛阵列: 对于这 16 个候选者，门禁系统强行禁止它们触碰昂贵的 RDOQ 引擎，而是让它们全部只经过廉价的普通 SQ 量化，并结合简易查表估算出一个极其粗糙的 Cost。
    3. 末位残酷淘汰: 硬件冒泡排序树接收这 16 个粗糙 Cost 并进行火速排序，当场无情抹杀排名靠后的 14 个选项，只留下金字塔尖的 Top-2 精英。
    4. 精英极深造: 此时，只有这历经千辛万苦幸存的 2 个 Elite Candidates，才被获准正式踏入极其吃面积与功耗的 4-Unit 深度 RDOQ 优化阵列。吞吐量从而被奇迹般地压制在了物理预算极限之内。

    6. 亮色度分治策略 (Luma-Chroma RDOQ Bypass)

    在实际硬件流水线中，针对亮色度采取非对称的量化策略，以追求极致的性价比与吞吐率。这是一种完全符合标准语法且 100% 保证编解码一致性（Mismatch Free）的经典工程权衡。

    核心优化：Luma 开启 RDOQ，Chroma 关闭 RDOQ
    由于人眼对亮度细节远比色度敏感，RDOQ 带来的压缩收益绝大部分集中在 Luma (亮度) 分量。强迫 Chroma (色度) 旁路 RDOQ，仅执行基础的标量量化 (SQ)，可在几乎不影响整体 BD-Rate 的前提下，节省可观的计算周期与面积开销。

    自然语言算法步骤 (Algorithm Steps)

    1. 分量侦测: 流水线控制端根据当前 TU 的颜色通道元数据，区分 Luma (Y) 与 Chroma (Cb/Cr)。
    2. 色度快速旁路 (Chroma Fast-Path): 若为色度通道，强制封锁 RDOQ 硬件入口使能，数据仅流过廉价的普通标量量化 (SQ) 模块，快速闭环并输出残差。
    3. 亮度深度精雕 (Luma RDOQ-Path): 若为亮度通道（且符合 4x4 等精英尺寸），则获准进入完整的 RDOQ 深度优化寻优阵列，以压榨极限的视觉与码流收益。
